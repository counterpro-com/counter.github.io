# Counter Pro – Complete GitHub Pages Project

Upload all files to GitHub. Settings → Pages → Deploy from branch → main → / (root).

Replace https://counterpro-com.github.io/counter.github.io/ with your real domain in index.html, both blog pages, robots.txt and sitemap.xml.

Add assets/favicon.png and assets/og-image.png.
